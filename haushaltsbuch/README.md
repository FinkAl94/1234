# Haushaltsbuch

Offline-fähige App für Einnahmen und Ausgaben (Kategorien, Auswertung, Werbungskosten, Krankenkasse mit Beihilfe/PKV, verschlüsselte Backups, PIN-Sperre).

Adresse nach Aktivierung von GitHub Pages: `https://<benutzername>.github.io/1234/haushaltsbuch/`

- Die Buchungen liegen nur im Speicher des Geräts, nie in diesem Repository.
- **Niemals Backup-, CSV- oder Screenshot-Dateien in dieses Repository hochladen.** Alles hier ist öffentlich.
- Bei Änderungen an den Dateien in `sw.js` die Version (`haushaltsbuch-vNN`) erhöhen.
